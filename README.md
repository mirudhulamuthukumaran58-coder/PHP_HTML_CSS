## Program Title

**BuildPro Builders – Responsive Builders Company Website (Without Database)**

## Objective

The objective of this project is to develop a responsive and user-friendly website for a builders and construction company using HTML, CSS, JavaScript, and PHP without a database. The website demonstrates web development concepts such as registration and login pages, form validation, hyperlinks, responsive design, and interactive user interfaces. The project aims to provide visitors with information about the company, its services, and contact details while showcasing front-end and basic PHP development skills.

## Software/Tools Used

* Visual Studio Code (VS Code)
* HTML5
* CSS3
* JavaScript (ES6)
* PHP
* XAMPP/WAMP (Apache Server for running PHP)
* Google Chrome / Microsoft Edge (Web Browser)
* Bootstrap Icons (Optional)
* Google Fonts (Optional)
